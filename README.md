# Ali Onur Interactive - Gaming Studio Portfolio

Bu repo, AAA / Bağımsız oyun stüdyosu tarzında modern bir portföy ve GitHub Pages vitrin sitesidir.

## 🚀 Özellikler
- **Cyberpunk / Oyun Stüdyosu Teması:** HUD göstergeleri, neon hatlar, CRT scanline ve vignette efektleri.
- **Etkileşimli Arka Plan:** HTML5 Canvas üzerinde çalışan neon ağ / parçacık simülasyonu.
- **Oyun Kartları & Vitrin:** Unreal Engine 5, Unity ve Godot projelerini öne çıkaran kart tasarımları.
- **Filtrelenebilir Repolar:** Motor, AI/Gameplay ve Shader/Araçlar kategorilerine göre anlık filtreleme.
- **Geliştirici Terminal Konsolu:** Daktilo (typewriter) efektli etkileşimli Linux konsol simülasyonu.
- **Tam Duyarlı (Responsive):** Mobil, tablet ve masaüstü uyumlu.

## 📦 GitHub Pages'e Canlıya Alma
1. Kodları GitHub hesabınızda `<kullanici_adiniz>.github.io` isimli bir repoya (veya herhangi bir repoya) push edin.
2. Reponun **Settings > Pages** sekmesine gidin.
3. Branch olarak `main` ve klasör olarak `/ (root)` seçip kaydedin.
4. Siteniz dakikalar içinde canlıya alınacaktır!
